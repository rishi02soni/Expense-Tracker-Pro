## 💰 Expense Tracker Pro

A modern full-stack **Expense Tracker Web Application** built using:

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  

Track your daily expenses, manage categories, and calculate total spending in real-time.

---

## 📌 Features

- Add New Expenses  
- Delete Expenses  
- Real-Time Total Calculation  
- Category Management  
- REST API Backend  
- MongoDB Database Storage  
- Responsive UI Design  
- Easy to Customize

## 🚀 Installation Guide
> 1️⃣ Clone Repository
```
git clone https://github.com/yourusername/expense-tracker-pro.git
cd expense-tracker-pro
```
> 2️⃣ Setup Backend
```
cd backend
npm install
```
> 3️⃣ Configure Environment Variables
```
Create .env file inside backend folder:
PORT=5000
MONGO_URI=mongodb://127.0.0.1:27017/expenseDB
```
> 4️⃣ Run Backend Server
```
npm start
Server will run on:
http://localhost:5000
```
>5️⃣ Run Frontend
```
Open:
frontend/index.html
or use Live Server in VS Code.
```
